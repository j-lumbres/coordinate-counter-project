`coordinates.csv` is adapted from the M3ED dataset:

- Title: `M3ED: Multi-Robot, Multi-Sensor, Multi-Environment Event Dataset`
- Creators: Kenneth Chaney, Fernando Cladera, Ziyun Wang, Anthony Bisulco, M. Ani Hsieh, Christopher Korpela, Vijay Kumar, Camillo J. Taylor, and Kostas Daniilidis
- Source: <https://m3ed.io/>
- Paper: Chaney et al., CVPR Workshops 2023
- Original license: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

Changes made for this repository:

- Extracted only 2D `(x, y)` coordinate pairs from the source event data
- Removed temporal, polarity, and other source fields
- Reformatted the extracted data as a CSV file
